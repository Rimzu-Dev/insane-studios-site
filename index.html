About

I'm Gavin, also known as Vibin or Loki. I'm an indie developer, modder, 3D modeler, and web developer, and the person behind Insane Studios. I'm 20 now and I've been making things on a computer for about as long as I can remember caring about it.

I started with web development at 15, which means five years of learning by doing, from small static pages to full single-page sites like this one. At 17 I picked up 3D modeling so I could actually build the things I was picturing, and since late 2023 I've been making games, turning those models and ideas into playable projects like Rally Horizons and Blockin.

About the Game

Blockin is a custom-built voxel crafting and game project focused on a clean, modern experience. It combines inventory management and crafting grids with classic block placement, breaking, and material management, all wrapped in custom-designed panels and HUD elements.

Blockin also ships with a custom launcher that starts the precompiled game seamlessly, so you can get straight to building. Compiling from source is reserved for advanced developers and mod developers.

Features

Precompiled Launcher

Starts the precompiled game right out of the box, with no setup required.

Modern UI and HUD

Custom-designed inventory and crafting grids with clean panel styling.

Voxel Mechanics

Classic block placement, breaking, and material management.

Multiplayer (In Development)

Multiplayer is in development and currently has bugs. Expect issues while it is being worked on.

Community Driven

Open for community code contributions, pull requests, and collaborative development.

Advanced and Mod Developers

Compiling from source is available for advanced developers and mod developers who want to modify the game.

Getting Started

  1. Clone or download the repository.
  2. Run the launcher to start the precompiled game.
  3. Launch Blockin and start building.

Advanced developers and mod developers can compile from source if they want to modify the game.
